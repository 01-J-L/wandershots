Android hardware bridge endpoints for local SMS dispatch.

Configuration Instructions

Link this management system directly to your SMSGate-enabled Android device to dispatch notification SMS messages using local SIM capabilities.

  1. Launch the SMSGate application on your Android hardware device.
  2. Ensure the Cloud server toggle is enabled.
  3. Retrieve the Username and Password generated by the app, and paste them into the corresponding inputs.
  4. Save the gateway settings first, then click Test Connection to run an automated transmission verification.
